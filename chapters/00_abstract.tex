\MakeAbstract{
    Unix V6++ 是面向操作系统课程实践的教学内核，原系统主要运行于 IA-32 传统 PC 平台，内核主体采用 C++ 实现。随着 RISC-V 开放指令集在系统软件教学中的使用增多，原系统的启动方式、中断模型、设备访问路径和用户程序格式难以通过简单更换编译目标完成迁移。本文围绕 Unix V6++ 的 RISC-V 移植与 Rust 重构展开，在保留 Unix V6 风格系统调用、进程语义、文件接口和 Shell 使用方式的基础上，重新实现平台相关层与用户态运行环境。

    当前系统面向 QEMU virt 平台和 OpenSBI 固件环境，内核使用 Rust 编写，少量汇编用于启动、Trap 入口和上下文切换。论文重点说明 RISC-V 启动流程、Sv39 地址空间、Trap 与系统调用框架、进程控制块、调度、fork/exec/wait/exit、ELF64/RISC-V 用户程序加载、信号处理、VirtIO 块设备、UART/TTY 和 Shell 交互等实现。文件系统和内存管理在本文中主要作为系统运行支撑条件出现，不作为单独设计重点。与重构前 main 分支相比，当前系统完成了从 IA-32/C++/PC 设备模型到 RISC-V/Rust/QEMU virt 平台的迁移，并形成可构建、可运行、可交互测试的教学操作系统框架。Rust 的所有权、生命周期、Drop 和 RAII 风格封装被用于表达页资源、内核栈、文件引用、inode 引用和中断保护等对象的释放边界，在保留底层可观察性的同时降低了资源管理路径分散带来的维护成本。
}{Unix V6++；RISC-V；Rust；操作系统移植；教学操作系统}

\MakeAbstractEng{
    Unix V6++ is an educational operating system kernel used in operating system courses. The original system targets the IA-32 PC platform and is mainly implemented in C++. As RISC-V has become more common in system software education, its boot process, interrupt model, device interface, and user program ABI require more than a change of compilation target. This thesis studies the RISC-V porting and Rust-based refactoring of Unix V6++, while preserving Unix V6-style system calls, process semantics, file interfaces, and shell behavior.

    The refactored system runs on the QEMU virt machine with OpenSBI. The kernel is written in Rust, with a small amount of assembly for boot code, trap entry, and context switching. The thesis discusses the RISC-V boot path, Sv39 address space, trap and system call framework, process control block, scheduling, fork/exec/wait/exit, ELF64/RISC-V program loading, signal handling, VirtIO block device support, UART/TTY, and shell interaction. File system and memory management are treated as supporting parts of the runtime environment rather than the central focus. Compared with the pre-refactoring main branch, the current system migrates Unix V6++ from an IA-32/C++/PC device model to a RISC-V/Rust/QEMU virt platform and provides a buildable, runnable, and interactively testable educational kernel. Rust ownership, lifetimes, Drop, and RAII-style wrappers are used to express the release boundaries of page resources, kernel stacks, file references, inode references, and interrupt guards, reducing scattered manual resource-management paths while keeping low-level behavior observable.
