\chapter{绪论}\label{chap:introduction}

操作系统连接硬件资源与应用程序，其实现牵涉特权级、地址空间、异常中断、进程调度、文件接口和设备驱动等多个层面。在计算机科学与技术专业的本科教学中，进程、页表、系统调用等概念若缺少可运行内核的支撑，学生往往难以判断它们在真实执行路径中的相互依赖。代码规模适中、结构清楚、便于调试的教学操作系统，使抽象概念能够落到可观察的内核行为上，因而成为操作系统课程中重要的实验材料。

本课题以同济大学 Unix V6++ 教学操作系统为基础，研究其面向 RISC-V 平台的移植与 Rust 重构。重构前的 Unix V6++ 面向 IA-32 架构，内核主体采用 C++ 编写；本文在保留 Unix V6 风格系统调用、进程语义和 Shell 使用方式的前提下，重新实现启动、中断异常、系统调用、进程管理、设备适配和用户程序支持等路径。文件系统和内存管理在本文中作为系统运行的支撑条件处理，不作为主要展开对象。系统目标是在 QEMU virt 机器上启动到可交互 Shell，并运行常见用户程序、文件命令、进程和信号测试。

\section{研究背景与意义}

操作系统课程的难点，来自硬件机制和软件抽象在执行路径中的交叉。一次 Shell 命令可能经过用户程序装载、文件描述符、系统调用、Trap 返回和进程调度；一次终端输入也可能触发设备中断、TTY 行规程和信号处理。若只有概念说明而缺少可运行内核，学生很难把这些机制放回同一条控制流中理解。

经典教材通常从概念层面讨论进程管理、内存管理、文件系统、输入输出和安全机制等主题\cite{tanenbaum2017modern,arpaci2019ostep}，为理解操作系统原理提供了基本框架。本科阶段的系统实践还需要规模可控、便于阅读和修改的内核作为实验对象。Unix V6 及其教学化衍生系统保留了进程、文件、设备和系统调用等基本结构，又避免了现代通用操作系统的代码规模，因而适合作为观察内核内部关系的材料\cite{ritchie_unix_1974,lions_unix_1996}。

同济大学 Unix V6++ 是面向操作系统教学开发的 Unix V6 风格实验系统。该系统将早期 Unix 的核心思想迁移到更容易获得的硬件平台，并以面向对象方式重构了进程、文件系统、设备和中断等模块。它保留了小型 Unix 内核的主要组成部分，学生可以通过阅读和修改系统代码，观察系统调用如何进入内核、进程如何被调度、文件如何通过 inode 和缓冲区访问磁盘，以及终端输入如何驱动 Shell 交互。陈闳中教授关于 Unix V6++ 教学实践的回顾也明确提出了让学生动手修改、调试内核的课程目标\cite{chenhz_unixv6pp}。

RISC-V 开源指令集架构近年在教学、科研与产业中被持续采用。其非特权规范定义基础指令、寄存器和用户态执行模型，特权架构规范则对异常、中断、页表和特权级切换等操作系统所需机制作出了明确描述\cite{riscv_unprivileged_20191213,riscv_privileged_20211203}。与传统封闭指令集相比，RISC-V 的开放规范更便于在系统软件教学中展开硬件抽象层的说明，学生可以在学习指令集和特权级机制的同时，分析操作系统如何利用这些机制实现地址隔离、异常处理和设备访问。

将 Unix V6++ 移植到 RISC-V 平台，可以把原有课程中的 Unix V6++ 实验习惯与 RISC-V 开放规范放入同一套系统。移植过程需要重新处理启动流程、地址布局、中断控制器、设备模型、用户程序 ABI 和构建系统，也提供了一条从固件入口到 Shell 命令返回的观察路径。

\section{国内外研究现状}

教学操作系统的设计目标通常侧重在有限代码规模内覆盖核心机制，对工业级完备性的要求相对次要。Unix V6 是这一方向的重要源头。它以简洁的代码实现了进程、文件、目录、设备和系统调用等基本机制，长期被用作理解 Unix 操作系统结构的经典材料。以 Unix V6 为思想来源的教学系统强调可读性和可修改性，适合用来展示操作系统各模块之间的配合关系。

MIT 的 xv6 是当前国际上应用较广的 Unix-like 教学操作系统。xv6 早期版本面向 x86，后续版本迁移到 RISC-V，并在 MIT 操作系统课程中用于讲解进程、页表、锁、文件系统和系统调用等主题\cite{xv6_book_2023}。xv6 代码量较小，结构清晰，注释和实验材料也较完备，许多高校将其作为操作系统课程的重要参考。不过，xv6 更强调从 Unix V6 思想出发重写一个小型教学内核，而 Unix V6++ 则更突出在本校课程体系中长期积累的教学接口、实验习惯和用户态环境。

除 xv6 外，OS/161、Pintos 等系统也被广泛用于操作系统教学。OS/161 常用于配合同步、虚拟内存和文件系统实验，Pintos 则强调从半成品内核出发逐步完成调度、用户程序和文件系统等功能\cite{holland_os161_2002,pfaff_pintos_2009}。这类系统能够训练学生的内核编程能力，但其设计背景、运行环境和实验组织方式各不相同。本文选择依托已有 Unix V6++ 教学基础完成平台迁移，重点放在原有教学系统如何进入 RISC-V/Rust 环境。

国内 RISC-V 操作系统教学也已形成若干实践。rCore 教程以 Rust 语言和 RISC-V 架构为基础，从批处理系统、地址空间、进程管理到文件系统逐步构造操作系统内核\cite{rcore_tutorial_v3}。该项目表明，Rust 的类型系统和模块化组织可以用于教学内核，也为 RISC-V 系统软件实践提供了较完整的实验路径。QEMU 则为 RISC-V 提供系统级仿真环境，可模拟 virt 机器、串口、PLIC、VirtIO 设备等硬件组件，降低教学实验对真实硬件的依赖\cite{qemu_riscv_doc}。

Rust 语言近年来逐渐进入系统软件开发领域。Rust 通过所有权、生命周期和类型检查等机制，不依赖垃圾回收即可提供内存安全能力\cite{rust_reference}。已有 Rust 内核研究也表明，内核仍需保留少量受控的 unsafe 抽象，但类型系统可以帮助收束资源管理和隔离边界\cite{levy_kernel_rust_2017}。内核开发仍需处理裸机启动、外设访问、页表修改和上下文切换等底层操作，无法完全避免 unsafe 代码；但 Rust 的模块系统、枚举、模式匹配和 trait 有助于表达复杂状态和抽象边界。对于教学内核而言，Rust 保留了接近硬件的控制能力，也能减少空指针、悬垂引用和资源释放错误给代码阅读带来的额外负担。

上述系统说明，小型教学内核在操作系统课程中仍具有稳定价值，RISC-V 与 Rust 则提供了新的实现基础。Unix V6++ 的迁移不能通过简单替换编译目标完成，启动入口、页表、中断、设备、用户程序格式和构建链都会随平台改变。本文以保留原有教学语义为前提，处理这些具体迁移问题。

\section{本文主要研究内容}

本文围绕 Unix V6++ 的 RISC-V 移植与 Rust 重构展开。系统启动和地址空间基础的迁移，使内核能够在 QEMU virt 平台上经由 OpenSBI 进入 Rust 入口，完成 BSS 段清零、串口初始化、页表建立和内核初始化\cite{opensbi_project}。内存管理部分服务于后续进程运行所需的 Sv39 页表、内核高地址映射、用户空间映射和 MMIO 映射，并接入页帧分配器，为内核对象、用户进程图像和内核栈提供页级资源。

中断、异常和系统调用框架的重构构成平台迁移的另一条主线。RISC-V 平台改用 \texttt{stvec}、\texttt{scause}、\texttt{sepc}、\texttt{sstatus} 等特权寄存器组织 Trap 处理，原 IA-32 平台中的 GDT、IDT、8259A 等机制随平台迁移被替换。本文实现统一 Trap 入口，在汇编层保存通用寄存器和关键控制状态，并在 Rust 层分发系统调用、时钟中断、外部中断和异常。系统调用接口保留 Unix V6 风格编号和语义。用户态 C 库封装 \texttt{ecall} 指令，内核从寄存器取得系统调用号和参数，再分发到进程管理、终端和文件接口等模块。

进程管理和用户程序支持部分覆盖进程控制块、进程状态机、独立内核栈、任务上下文切换、sleep/wakeup 和调度逻辑。用户程序采用 ELF64/RISC-V 格式，内核在 \texttt{exec} 过程中解析 ELF 头和程序头，将 text、data 和 stack 区域映射到用户空间，并构造 argc/argv 用户栈。系统实现 \texttt{fork}、\texttt{exec}、\texttt{wait}、\texttt{exit} 等核心进程系统调用，并提供基本信号机制，用于处理终端中断、非法访问和用户显式发送的信号。

设备、终端和用户交互环境用于检验上述内核路径。文件系统继续提供 Unix V6++ 的 inode、目录、文件描述符和缓冲区接口，本文关注这些接口同进程、系统调用和设备层的连接。设备层从 PC 平台的 ATA/IDE 和键盘显示路径，迁移到 QEMU virt 平台上的 UART、PLIC 和 VirtIO Block。终端部分基于串口输入输出和 TTY 行规程支撑 Shell，用于验证命令执行、管道、重定向和常见用户程序。

相较重构前的 main 分支，当前系统的变化集中在体系结构、实现语言和运行环境三个方面：IA-32 转为 RISC-V，C++ 内核转为 Rust 内核，传统 PC 设备模型转为 QEMU virt、OpenSBI、PLIC、UART 和 VirtIO 组成的仿真平台。第 7 章的构建与测试验证说明，这些变化已经进入用户库、Shell、文件系统镜像和 QEMU 启动流程。

\section{本文组织结构}

全文共八章。第 1 章说明课题背景、相关教学操作系统和本文研究内容；第 2 章分析原 Unix V6++ 结构、当前系统架构和移植方案；第 3 章讨论 RISC-V 启动、地址空间和页资源管理；第 4 章讨论 Trap、中断异常和系统调用；第 5 章讨论进程模型、调度、进程生命周期、ELF 加载和信号；第 6 章讨论文件接口、VirtIO 块设备、TTY 与 Shell；第 7 章给出构建运行方式和功能测试结果；第 8 章总结工作并说明后续完善方向。
